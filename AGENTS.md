# AGENTS.md — launchcontainers

Read these first:

1. `HANDOFF.md`: open work and what is left to do. Update it when you finish or
   hand off a task.
2. `Claude.md`: project context. Parts of it are out of date; `HANDOFF.md` lists
   which ones.
3. `CHANGELOG.md`: what was changed in lc, the problem and why. Every change you
   make gets an entry there, on its own branch from `origin/main`, through a PR
   to the fork's `main` that you merge yourself once the tests pass; the PR to
   upstream stays the maintainer's (`Claude.md`, "How changes land").
